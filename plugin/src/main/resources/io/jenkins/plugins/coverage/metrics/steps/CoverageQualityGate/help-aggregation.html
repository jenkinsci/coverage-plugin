Defines how the values of the selected metric are aggregated before the quality gate is evaluated.
  • Overall (default): the value of the metric for the whole selection, e.g., the line coverage of all lines, the sum of the cyclomatic complexity of all methods, or the mean value of percentages like the class cohesion.
  • Maximum: the largest value of all elements, e.g., the method with the highest cyclomatic complexity or the file with the best line coverage.
  • Minimum: the smallest value of all elements, e.g., the file with the worst line coverage.

The maximum and minimum are selected from the elements that provide the metric: methods for method metrics (e.g., cyclomatic complexity), files for coverage metrics (e.g., line or branch coverage), and classes for all other metrics. If a report provides the values of a metric on a coarser level only (e.g., the complexity of files rather than of methods), then these values are used instead. Files without code are ignored. Container metrics (e.g., file or package coverage) provide only an overall value.

For delta baselines, the difference between the aggregated values of the build and the reference is evaluated, e.g., the change of the maximum cyclomatic complexity of all methods.
